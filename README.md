# Touchstone 3: North Star Bakery

A five-page responsive website for North Star Bakery, styled with a shared mobile-first CSS design system.

## Pages

- `index.html` — bakery introduction and navigation to key tasks
- `products.html` — product categories and availability note
- `about.html` — bakery story
- `media.html` — bakery illustration gallery
- `contact.html` — labeled contact and preorder form
- `assets/images/` — bakery photos, logo, and illustration
- `assets/audio/` — bakery welcome audio
- `assets/video/` — behind-the-scenes bakery video

## Preview locally

Open `index.html` in a browser, or serve this folder with a local static web server. The site has no build step or external dependencies.

The contact form is currently a front-end demonstration and does not send messages. Connect it to a form service before using it with customers.

See [DESIGN-EXPLANATION.md](DESIGN-EXPLANATION.md) for the design decisions and submission notes.
